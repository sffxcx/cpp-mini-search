# MiniSearch - Локальный движок полнотекстового поиска на C++17

## 🎯 Описание проекта

**MiniSearch** — это легкий HTTP-сервер для полнотекстового поиска по набору документов. Проект демонстрирует работу с алгоритмами поиска, структурами данных и базами данных на C++17.

Основные возможности:
- Полнотекстовый поиск с ранжированием по релевантности
- Инвертированный индекс для быстрого поиска
- Алгоритм TF-IDF для оценки важности документов
- Хранение документов в SQLite для персистентности
- HTTP API для взаимодействия с поисковым движком

## 🛠 Технологии

- **C++17** — современный стандарт C++
- **SQLite3** — хранение документов и метаданных
- **POSIX Sockets / Winsock** — работа с сетью
- **std::thread** — многопоточная обработка запросов
- **std::unordered_map** — инвертированный индекс
- **CMake** — система сборки
- **Docker** — контейнеризация для кроссплатформенного запуска

Никаких тяжелых фреймворков! Только стандартная библиотека C++17, SQLite и системные вызовы.

## 🌍 Кроссплатформенность

Проект полностью кроссплатформенный и работает на:
- ✅ Windows (через Winsock)
- ✅ Linux (через POSIX sockets)
- ✅ macOS (через POSIX sockets)
- ✅ Docker (контейнеризированная версия)

Используется условная компиляция (`#ifdef _WIN32`) для автоматического выбора правильных системных вызовов в зависимости от операционной системы.

## 🏗 Архитектура

Проект имеет модульную архитектуру:

```
MiniSearch/
├── include/
│   ├── text_parser.h      # Токенизация и нормализация текста
│   ├── document_store.h   # Работа с SQLite (хранение документов)
│   ├── search_engine.h    # Инвертированный индекс и TF-IDF
│   └── http_server.h      # HTTP-сервер для обработки запросов
├── src/
│   ├── main.cpp           # Точка входа
│   ├── text_parser.cpp
│   ├── document_store.cpp
│   ├── search_engine.cpp
│   └── http_server.cpp
├── data/                  # Тестовые документы
├── CMakeLists.txt
├── Dockerfile             # Конфигурация Docker-контейнера
├── .dockerignore          # Исключения для Docker
└── README.md
```

### Компоненты:

1. **TextParser** — обрабатывает текст: токенизация, нормализация, удаление стоп-слов
2. **DocumentStore** — хранит документы в SQLite для персистентности
3. **SearchEngine** — строит инвертированный индекс в памяти, реализует TF-IDF ранжирование
4. **HttpServer** — простой сервер на сокетах, обрабатывает GET-запросы

## 📦 Сборка и запуск

### Вариант 1: Запуск через Docker (рекомендуется)

Самый простой способ запустить проект на любой операционной системе.

#### Сборка образа
```bash
docker build -t mini-search .
```

#### Запуск с сохранением данных
```bash
docker run -p 8080:8080 -v $(pwd)/data:/app/data --name my-mini-search mini-search
```

**Что здесь происходит:**
- `-p 8080:8080` — пробрасывает порт 8080 из контейнера на ваш компьютер
- `-v $(pwd)/data:/app/data` — монтирует папку `data` для сохранения базы данных SQLite
- `--name my-mini-search` — дает контейнеру удобное имя

#### Тестирование
```bash
# Поиск по слову
curl "http://localhost:8080/search?q=memory"

# Поиск по фразе
curl "http://localhost:8080/search?q=C%2B%2B%20algorithms"

# Проверка статуса
curl "http://localhost:8080/status"
```

#### Управление контейнером
```bash
# Остановить контейнер
docker stop my-mini-search

# Запустить снова
docker start my-mini-search

# Посмотреть логи
docker logs my-mini-search

# Удалить контейнер
docker rm my-mini-search
```

## 🔍 Алгоритмы

### Инвертированный индекс

Для каждого слова хранится список документов, в которых оно встречается:
```
слово -> [(doc_id, tf), (doc_id, tf), ...]
```

Поиск работает за O(1) для каждого слова в запросе.

### TF-IDF ранжирование

**TF (Term Frequency)** — частота термина в документе:
```
TF(t, d) = количество вхождений t в d / общее количество слов в d
```

**IDF (Inverse Document Frequency)** — обратная частота документа:
```
IDF(t) = log(общее число документов / число документов содержащих t)
```

**Скор документа:**
```
Score(d, query) = Σ TF(t, d) * IDF(t) для всех t в запросе
```

## 🔧 Расширение

Поместите текстовые файлы (.txt) в папку `data/` и перезапустите сервер.

### Изменение порта

Отредактируйте константу `DEFAULT_PORT` в `src/main.cpp`.

## ⚠️ Ограничения

- Работает только с текстовыми файлами в кодировке UTF-8
- Простой парсер (может не справиться с HTML или PDF)
- Нет поддержки кириллицы в стоп-словах (только английские)
- Индекс строится в памяти (ограничен размером RAM)
- Нет реального времени обновления индекса (только при перезапуске)
